# sns-bot-media

[sns-bot](https://github.com/sjfteexh66-coder/sns-bot) 봇이 스레드·인스타에 이미지를 게시할 때 쓰는 **공개 저장소**예요.

스레드·인스타 API는 누구나 열 수 있는 이미지 주소만 받기 때문에, 봇이 게시하는 순간에만 이미지를 여기에 잠깐 올리고 그 주소를 넘겨요.
곧 SNS에 공개될 이미지만 올라오니 공개 저장소여도 괜찮아요.

- 직접 파일을 올리거나 지울 필요 없어요. 봇이 알아서 관리해요.
- 이 저장소를 **비공개로 바꾸면** 이미지 게시가 실패해요.
- 비밀값(토큰 등)은 절대 여기에 올리지 마세요.
